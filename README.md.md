# PlayZone – Gaming Cafe & Console Lounge Manager

A web-based management platform built for the **Software Engineering and System Design (24CS301PC311)** course at **SR University** (B.Tech CSE, III Year I Semester).

## Key Features
- **Role-Based Access Control (RBAC):** Dedicated views for Gamer, Desk Operator, Hardware Technician, Cafe Manager, and Public Visitor.
- **Station & Game Directory:** Filterable PC Zone, PS5 Lounge, Racing Sim, and VR Booth listings with specs, installed games, and live availability.
- **Live Timers & Integrated Billing:** Per-second countdown timers, +30 min extensions, cafe snack add-ons, and printable PDF invoices.
- **QR Invoice Verification:** Public verification portal (try sample ID `PZ-2026-1042`) without requiring login.
- **3-Stage Hardware Maintenance Pipeline:** Desk Operator flags faulty gear -> Station auto-locks -> Technician submits repair cost -> Cafe Manager approves/rejects budget -> Station unlocks.
- **Admin Console & Audit Logs:** Real-time revenue KPIs, station management, and timestamped system audit trails.
